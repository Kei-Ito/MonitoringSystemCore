# フロントエンド パフォーマンス最適化施策

## 背景

モニタリングシステムにおいて、長時間の計測や高頻度のサンプリングを行うと、時系列データ（`timeSeries`）の要素数が数万〜数十万件に達することがあります。
Vue.js のリアクティブシステムは、デフォルトでオブジェクトや配列を深く監視（Deep Watch）し、すべてのプロパティに対してプロキシを作成します。
このため、大量のデータポイントを持つ配列をそのままストアの状態として保持すると、以下の問題が発生していました。

1. **メモリ使用量の増大**: 各データポイントに対してプロキシオブジェクトが生成されるため、生データの数倍のメモリを消費し、ブラウザのメモリ使用量が1GBを超える場合がある。
2. **CPU負荷の上昇**: データの追加や参照時にプロキシのオーバーヘッドが発生し、特にグラフ描画時のデータ加工処理などでCPU使用率が高くなる。

## 施策概要

これらの問題を解決するため、以下の2点の施策を実施しました。

1. **`markRaw` による時系列データの非リアクティブ化**
2. **`dataVersion` による手動変更検知**

### 1. `markRaw` による時系列データの非リアクティブ化

Vue 3 の `markRaw` API を使用して、時系列データ配列（`timeSeries`）をリアクティブシステムの監視対象外にしました。
これにより、Vue は配列およびその内部の要素に対してプロキシを作成しなくなり、ネイティブ配列と同等のメモリ効率とアクセス速度を実現しました。

**対象ファイル**: `apps/frontend/src/pinia/channelValuesStore.ts`

```typescript
import { markRaw } from "vue";

// ...

setTimeSeries(channelUuid: string, timeSeries: RuntimeValue[]) {
    // ...
    // 配列を markRaw でラップしてストアに保存
    this.channelValues[channelUuid].timeSeries = markRaw(timeSeries);
    // ...
}
```

### 2. `dataVersion` による手動変更検知

`markRaw` を適用すると、配列への要素追加（`push`など）を行っても、Vue はその変更を検知できなくなります（リアクティブ性が失われるため）。
そのため、グラフコンポーネントなどがデータの更新を知るための仕組みとして、別途 `dataVersion`（数値型）プロパティを導入しました。

データ更新時には、配列への操作とともに `dataVersion` をインクリメントします。

**対象ファイル**: `apps/frontend/src/pinia/channelValuesStore.ts`

```typescript
interface StoreChannelValue extends ChannelValue {
    realtimeSeries: RuntimeValue[];
    /**
     * データのバージョン管理用カウンター
     * timeSeriesをmarkRawで非リアクティブ化しているため、
     * 変更検知のためにこの値をインクリメントして使用する
     */
    dataVersion: number;
}

// ...

_appendTimeSeries(channelUuid: string, runtimeValue: RuntimeValue) {
    // ...
    // 配列への追加（リアクティブ更新はトリガーされない）
    this.channelValues[channelUuid].timeSeries.push(runtimeValue);
    // バージョンを更新して変更を通知
    this.channelValues[channelUuid].dataVersion++;
}
```

### コンポーネント側での対応

グラフコンポーネント（`LineChart.vue`）では、`computed` プロパティ内で `dataVersion` にアクセスすることで、明示的に依存関係を作成します。
これにより、`timeSeries` 配列自体が非リアクティブであっても、`dataVersion` が変化したタイミングで再計算が走り、グラフが更新されるようになります。

**対象ファイル**: `apps/frontend/src/components/Charts/LineChart.vue`

```typescript
const seriesData = computed(() =>
  props.series.map((s) => {
    // dataVersion にアクセスしてリアクティブな依存関係を作成する
    // これがないと配列の中身が変わっても再計算が走らない
    const _version = (s as any).dataVersion;
    void _version; // 値は使わないがアクセスした事実が必要

    const data = s.timeSeries ?? [];
    // ...
  }),
);
```

## 効果

* **メモリ使用量の削減**: プロキシ生成が抑制され、大量データを保持してもメモリ消費が大幅に抑えられます。
* **パフォーマンス向上**: プロキシのオーバーヘッドがなくなり、データの初期化や参照が高速化されました。また、`dataVersion` による制御で、必要なタイミングでのみ再描画が行われるようになりました。
